Lesson 12: Jenkins Fundamentals

Continuous Integration and automation with Jenkins

← Back to Linux Basics and DevOps Automations Page

What is Jenkins?

Jenkins is an open-source automation server used to implement Continuous Integration and Continuous Delivery (CI/CD). It automates building, testing, and deploying applications.

Why Jenkins is Important in DevOps

  • Automates repetitive build and test tasks
  • Detects issues early in the development cycle
  • Improves software quality and release speed
  • Integrates with many DevOps tools

Jenkins Architecture

  • Jenkins Controller: Manages jobs and scheduling
  • Agents (Nodes): Execute build and test tasks
  • Plugins: Extend Jenkins functionality

Installing Jenkins (Overview)


# Ubuntu example
sudo apt update
sudo apt install openjdk-11-jdk
sudo apt install jenkins
sudo systemctl start jenkins
sudo systemctl enable jenkins

Jenkins Jobs

  • Freestyle Jobs
  • Pipeline Jobs
  • Multibranch Pipelines
  • Folder-based Jobs

Plugins and Integrations

  • Git and GitHub integration
  • Maven, Gradle, and Docker plugins
  • Slack and email notifications
  • Cloud integrations (AWS, Azure)

Common Jenkins Use Cases

  • Automated code builds
  • Running unit and integration tests
  • Deploying applications
  • CI/CD pipeline orchestration

What You Learned

  • Jenkins fundamentals and purpose
  • Core Jenkins components
  • Jobs, plugins, and integrations
  • How Jenkins fits into DevOps workflows
