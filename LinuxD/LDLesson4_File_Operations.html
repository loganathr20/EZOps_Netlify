Lesson 4: Linux File Operations

Managing files and directories efficiently in Linux

← Back to Linux Basics and DevOps Automations Page

Introduction to File Operations

Linux file operations allow DevOps engineers to manage configuration files, logs, scripts, and application data efficiently across servers.

Creating Files and Directories

  • touch – create empty files
  • mkdir – create directories
  • mkdir -p – create nested directories

Viewing File Contents

  • cat – display file content
  • less and more – paginated viewing
  • head and tail – view beginning or end of files

Copying and Moving Files

  • cp – copy files and directories
  • cp -r – recursive directory copy
  • mv – move or rename files

Deleting Files and Directories

  • rm – remove files
  • rm -r – remove directories recursively
  • rm -f – force delete without confirmation

Searching Files in Linux

  • find – search files by name, type, size
  • locate – fast file search using index
  • grep – search text inside files

File Operations in DevOps Use Cases

  • Managing application configuration files
  • Log file analysis and cleanup
  • Backup and restore operations
  • Deployment artifact handling
