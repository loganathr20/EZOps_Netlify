Introduction to Linux HealthCheck

Linux HealthCheck is the backbone of reliable DevOps operations. By continuously monitoring CPU, memory, disk, network, and system load, administrators can proactively prevent outages, optimize performance, and maintain service reliability. A well-structured health check also ensures compliance, security, and long-term stability of DevOps platforms.

Linux HealthCheck

Monitor CPU, Memory, Disk usage, and system logs efficiently.

  1. Check CPU with top or htop
  2. Monitor disk space with df -h
  3. Review logs using journalctl

CPU Monitoring & Analysis

CPU utilization is critical for server performance. Monitor per-core usage to identify bottlenecks and optimize scheduling.

  • top or htop to view live CPU usage.
  • mpstat -P ALL 5 to see per-core utilization every 5 seconds.
  • Watch for consistently high load averages exceeding CPU core count.
  • Identify CPU-intensive processes: ps aux --sort=-%cpu

Memory & Swap Monitoring

  • Check memory usage: free -h, vmstat 5
  • Detect memory leaks by monitoring top or smem over time
  • Monitor swap usage and avoid excessive swapping which degrades performance
  • Optimize caching and buffer usage for better memory efficiency

Disk Space & I/O Monitoring

  • Check disk usage: df -h, du -sh /path
  • Monitor read/write operations: iostat -x 5, iotop
  • Watch for inode exhaustion and ensure sufficient free space
  • Optimize logs and temp files to reduce disk usage

Network Monitoring & Troubleshooting

  • Monitor interfaces: ifconfig or ip addr
  • Check active connections: netstat -tulnp, ss -tulnp
  • Measure latency: ping, mtr
  • Monitor bandwidth: iftop, nload
  • Log suspicious traffic or unexpected connections

Service & Process HealthCheck

  • List processes by resource usage: ps aux --sort=-%cpu, ps aux --sort=-%mem
  • Check service status: systemctl status nginx, systemctl is-active sshd
  • Restart failing services automatically using scripts or cron
  • Monitor background jobs and CI/CD tasks for performance issues

Log Monitoring & Auditing

  • Check system logs: /var/log/syslog, /var/log/messages
  • Monitor authentication: /var/log/auth.log
  • Use journalctl for centralized log review
  • Automate parsing logs for errors and alerts using scripts

Security Checks & Compliance

  • Verify firewall status: sudo ufw status or iptables -L
  • Check SELinux/AppArmor modes and alerts
  • Scan for vulnerable packages: apt list --upgradable or yum check-update
  • Ensure correct file permissions and ownership on critical directories
  • Monitor failed login attempts and SSH brute-force attempts

Automation & Scheduled HealthChecks

  • Create cron jobs for automated health checks
  • Example: */5 * * * * /usr/local/bin/linux_healthcheck.sh
  • Generate daily HTML reports for review
  • Send alerts via email, Slack, or webhooks when thresholds are exceeded

Performance Optimization Tips

  • Limit resource-hogging processes using nice and renice
  • Enable caching for frequently used services
  • Use swap efficiently and avoid overcommit
  • Regularly archive logs and clean temp directories
  • Monitor trends and scale resources proactively
